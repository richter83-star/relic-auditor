# Upgrade and compatibility

v0.8.x and v0.9.0 reports open through one canonical compatibility loader and
are never rewritten merely by opening them. Legacy field names are normalized
in memory. Reports without evidence hashes can be previewed but must be rescanned
before asset export.

Free remains the production default. Hosts that previously exposed Product
Opportunities should inject Pro. Only a verified host should inject Premium.
There is deliberately no CLI `--premium` switch.

Build Pack schema `1.0` is new and independent from the historical Opportunity
object schema. Consumers should validate canonical content and checksums rather
than relying on directory names.
