# Relic Auditor 1.0.2 release notes

Relic Auditor 1.0.2 is primarily a usability and product-flow release. It preserves the v1.0.1 analysis, evidence, Build Pack, licensing, updater, and Supervisor systems while making the desktop answer easier to understand.

## Focused journey

- Replaces permanent Scan / Results / Reports tabs with Scan → Answer → Prepare → Build.
- Gives each primary screen one dominant action.
- Makes the strongest recommendation the center of the Answer.
- Moves prior reports into History.
- Moves plan, update, storage, and secondary configuration into Settings.
- Renames the expert console to Technical Evidence and its Overview tab to Evidence Summary.
- Keeps raw evidence, provider diagnostics, and advanced scan controls hidden until deliberately requested.

## Honest inactive infrastructure

- Replaces inactive production license activation controls with a plan-only screen.
- Marks Pro and Premium as coming soon while keeping service-level entitlement enforcement fail-closed.
- Replaces raw update exceptions in normal dialogs with a stable unavailable message.
- Retains exact updater diagnostics under a deliberate Settings disclosure.

## Safety and compatibility

- Scanned targets remain read-only and are never imported, executed, installed, modified, moved, renamed, or deleted.
- Build Pack generation remains deterministic and approval-gated.
- Assisted Build retains exact capability approval, managed-workspace confinement, change review, and audit-ledger requirements.
- Historical v1.0.1 reports remain loadable.
- Existing CLI interfaces are unchanged.
- Authenticode requirements and updater trust roots are unchanged.

## Release status

This document describes the v1.0.2 internal release candidate. It does not create or authorize a tag, GitHub Release, public installer publication, package-index publication, or stable updater activation.
