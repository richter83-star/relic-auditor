# Relic Auditor 0.10.0 release notes

v0.10.0 adds the Product Builder Bridge: choose a supported Opportunity,
prepare a deterministic Build Pack, approve exact reusable assets, export an
isolated verified bundle, and hand it to Codex, Claude Code, or a generic coding
agent in a later separately approved session.

It adds canonical IDs and JSON, evidence-linked asset policy, new-work tasks,
content-addressed approvals, atomic export and cleanup, checksums, bounded
provider enrichment, CLI lifecycle commands, and a five-step accessible Results
wizard without adding a fourth top-level tab.

v0.10.0 does not execute coding agents or target code, launch shell commands,
install dependencies, access the network without explicit host consent, mutate
the target or Git remotes, deploy, publish, send messages, spend money, or supply
an OS sandbox.
