## Why this branch exists

The repository developed two disconnected histories. The validated v0.12 release line contains the Product Builder Bridge, licensing, approval-gated Supervisor/runtime, secure updater/trust roots, LLM health, Windows installer lifecycle, and their regression suites. The later `main` line contains useful Resurrection Mode and Technical Truth fixes but does not contain those v0.12 systems.

A normal merge is therefore not safe. This branch starts from the exact validated v0.12 commit and ports later work selectively.

## RC packaging rules

- frozen source is generated from the exact checked-out PR-head commit using `git archive`
- the frozen source SHA-256 is computed before installer construction and passed explicitly to the installer build script
- the build script refuses to proceed without an expected source SHA-256
- both the checked-out tree and frozen source test suites run before packaging
- bundled and installed CLI smoke include audit, acquisition, and Resurrection Mode
- GUI smoke, clean install, in-place upgrade, stale-runtime cleanup, user-config preservation, PATH cleanup, and uninstall remain mandatory gates
- unsigned installers remain internal test artifacts; the updater remains fail-closed unless configured trust requirements are satisfied
