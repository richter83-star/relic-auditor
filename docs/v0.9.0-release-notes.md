# Relic Auditor 0.9.0

The Product Opportunity Engine turns deterministic repository evidence into
canonical Opportunity records. Free retains the complete offline audit; Pro
adds evidence-backed Opportunities; Premium is reserved for roadmap and later
Build Pack capabilities.

The compatibility loader opens legacy v0.8 reports without rewriting them.
Historical records lacking source hashes remain readable but require a rescan
before any future asset reuse.
