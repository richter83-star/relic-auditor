# Relic Auditor 0.11.0 release candidate

v0.11.0 adds the approval-gated Assisted Build Supervisor and the signed-plan
licensing client.

## What changed

- The Product Builder Bridge now exports its Build Pack when the review wizard
  finishes instead of closing without a visible result.
- A numbered five-step desktop flow verifies the pack, creates an isolated
  workspace, selects a builder, requires exact capability approvals, and shows
  the complete changed-file result.
- Codex and Claude Code builder proposals are constrained profiles. Neither is
  allowed to publish, deploy, install dependencies, use Git, or perform an
  external action.
- Immutable action IDs, immutable grants, a hash-chained ledger, pre-action
  checkpoints, rollback, resource budgets, secret-redacted logs, pause/resume,
  diffs, and an unpublished candidate record are enforced by the supervisor.
- The CLI exposes the same lifecycle through `relic build`.
- Plan status and license management are visible in the desktop header and
  through `relic license`.
- Signed license tokens are device-bound, time-bound, verified offline, and
  stored in the operating-system credential vault.
- The scan-target trust statement now distinguishes read-only auditing from
  later, separately approved execution in a managed workspace.

## Honest release limits

- Production activation is not provisioned in this RC; without a pinned
  production public key, every installation remains Free.
- The Claude Code builder is a developer preview pending Anthropic approval for
  third-party Claude.ai subscription integration.
- A candidate remains local and review-required. There is no publication,
  deployment, tag, GitHub Release, payment, or messaging action.
- Pause/cancel applies between actions. An active process is bounded by its
  timeout rather than interactively terminated in v0.11.
- The supervisor is not a VM, separate Windows account, or firewall. Provider
  sandboxing and a disposable VM remain necessary for untrusted native builders.

See [Assisted Build Supervisor](assisted-build-supervisor.md) and
[Signed plan licensing](licensing.md) for the full trust model.
