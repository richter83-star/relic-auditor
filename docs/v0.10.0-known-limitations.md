# Known limitations

- A Build Pack is decision support, not proof the product will work or sell.
- License classification is not legal advice and does not prove ownership.
- Generated acceptance criteria are unverified until a later approved build
  session executes them.
- External market, pricing, and GTM claims remain hypotheses until validated.
- Local entitlement injection is not a production licensing system.
- v0.10.0 does not execute coding agents or provide an OS security sandbox.
- Windows junction detection uses platform file metadata and must still be
  verified on the release runner.
- Process-capable supervision is deferred to v0.11.0; build verification,
  bounded repair, re-audit, and readiness dossiers are deferred to v1.0.0.
