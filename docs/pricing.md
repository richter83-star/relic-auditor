# Relic Auditor plans and pricing

| Plan | Availability | Included |
|---|---|---|
| Free | $0 | Local scans, core results, reusable assets, risks, reports and history. |
| Pro | Pricing to be announced; public checkout is not open | Product Opportunity analysis and recommendations. |
| Premium | Pricing to be announced; public checkout is not open | Pro capabilities, deterministic Build Packs, builder handoffs and supported Assisted Build actions. |

The desktop includes a preview of opportunity selection and product preparation
on Free. Creating and exporting a Build Pack requires Premium.

## Owner and invited testing

Owner testing does not require a purchase. A signed Premium test license can
be issued for a specific installation. In the updated app, open **Settings →
Plan → Manage plan**, copy the installation ID, and send it to the issuer.
Use **Import license file** to activate the returned file. The app verifies the
signature, installation ID and expiration before enabling Premium.

Premium access enables the implemented plan capabilities. It does not enable
unimplemented providers, bypass build-action approvals, or activate automatic
software updates. Experimental Ghidra analysis is not sold as a production
capability.

## Purchasing

Public subscriptions are not currently available. Approved prices and the
official checkout link will be listed here when purchasing and paid license
delivery are ready. Importing an owner test license does not start a subscription
or charge a payment method.

See [licensing](licensing.md) for activation details and
[the README](../README.md) for current release availability.
