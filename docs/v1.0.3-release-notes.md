# Relic Auditor 1.0.3 release notes

Relic Auditor 1.0.3 is a focused-flow correction candidate. It preserves the
v1.0.2 analysis, evidence, Build Pack, Supervisor, licensing, updater, and
read-only target-safety boundaries while tightening the two screens reviewed
after the v1.0.2 Windows validation pass.

## Opportunity chooser

- Replaces six oversized action cards with a compact ranked list.
- Keeps one primary action on the screen: **Select opportunity**.
- Shows rank, evidence strength, effort, and reusable-asset count in each row.
- Keeps the highlighted opportunity's complete summary visible below the list.
- Supports keyboard focus, double-click selection, word wrapping, and narrow
  window reflow without a horizontal scrollbar.

## Contextual Technical Evidence

- Opens opportunity evidence scoped to the exact originating opportunity.
- Updates the Opportunities tab count to state that the view is scoped.
- Preselects the scoped record and immediately fills the complete-record detail
  pane.
- Restores the complete opportunity table when the user returns to the focused
  product flow.
- Keeps generic Technical Evidence entry unscoped.

## Accessibility and validation

- Adds accessible names and descriptions to ranked opportunity and evidence
  tables.
- Adds automated checks for keyboard focus, minimum-width reflow, unclipped
  controls, contextual selection state, and populated evidence details.
- Retains existing Windows 100%-200% display-scaling and complete source-suite
  gates.

This document describes an internal v1.0.3 correction candidate. It does not
create or authorize a tag, GitHub Release, public installer publication,
package-index publication, stable updater activation, or any change to updater
trust roots.
