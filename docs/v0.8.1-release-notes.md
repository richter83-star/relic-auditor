# Relic Auditor v0.8.1 release notes

A focused Windows dashboard redesign and DPI/layout hotfix. The analysis
engine, report schemas, Claude Code provider behaviour, CLI behaviour, safety
model, and deterministic results are unchanged from v0.8.0.

## Evidence Console redesign

The desktop dashboard now carries the Relic Auditor product identity: a
true-black canvas, neon yellow for primary action and selection, acid lime for
verified state, a lighter green for active evidence, amber for advisory, red
reserved for genuine failure, and restrained off-white body text on layered
dark panels with hairline borders.

- **New `dashboard/theme.py`** holds every colour, spacing step, radius, and
  type size. Widgets no longer embed raw style strings; they read tokens or ask
  for the compiled stylesheet.
- **New `dashboard/components.py`** provides the reusable pieces: `RelicPanel`,
  `EvidenceCard`, `MetricCard`, `StatusBadge`, `PrimaryButton`,
  `SecondaryButton`, `PathSelector`, `ProviderStatusCard`, `ScanProgressPanel`,
  `EmptyState`, `FindingsTable`, plus `ElidedLabel` and `hairline`.
- Fonts use system-safe stacks: Bahnschrift (condensed display) for headings
  and numerals, Segoe UI Variable Text for controls and tables, Cascadia Mono
  where monospace helps, each with fallbacks.

## Information architecture

Every previous function is preserved, reorganised into: header (identity,
Evidence Console, local-first/read-only/no-execution indicator, version, live
provider status); scan configuration (target, output, mode, provider selection,
readiness check, primary action); active scan (stage, elapsed, files inspected,
project roots, cancel); estate overview (compact metric strip); results
workspace (nine tabs, report actions); and a provider panel that stays visible
and usable.

## Windows DPI and layout fixes

Each defect listed against v0.8 is addressed, with a regression test:

- "Run read-only audit" is no longer vertically clipped. Text-bearing controls
  derive their minimum height from font metrics via `theme.control_height`
  rather than a fixed pixel height, so 100%-200% Windows scaling grows them.
- "Claude Code / Claude Max" is no longer horizontally clipped; the combo
  reserves width for its longest entry and the billing model is explained in
  the provider card instead of being crammed into the control.
- Provider status can no longer fall below the window: the whole configuration
  column is a scroll area.
- The sidebar scrolls vertically and never shows a horizontal scrollbar.
- Metric cards are compact with a Fixed vertical policy, so they no longer
  balloon into large empty rectangles, and the strip reflows to the widest row
  that measurably fits rather than to a guessed width threshold.
- Metric captions reserve two wrapped lines, so "ACQUISITION FINDINGS" no
  longer loses its second line.
- Table columns are fitted by a water-filling pass that both grows and shrinks
  columns, removing the spurious horizontal scrollbar; the readable floor is
  based on average glyph width so several columns can still fit.
- Row heights follow font metrics; category and status text is not cropped.
- Disabled controls keep a readable foreground instead of fading into the
  canvas.
- Scan completion is unmistakable (badge, lime progress, summary sentence) and
  report-export state is a separate badge from scan state.
- Progress is indeterminate whenever a true percentage is unavailable; a fake
  percentage is never displayed.
- The Candidates tab no longer forces a ~1100px minimum on the workspace
  (its action row and safety note are on separate lines), which was pushing the
  report actions off-screen at 1366x768.
- Tab labels scroll rather than elide to unreadable stubs.
- Empty tables state why they are empty instead of rendering a blank grid.
- Below 980 logical px the console stacks its panels vertically, with both
  panes given real height so the primary action never lands below the fold.

## Behaviour

- A second click cannot start a concurrent audit while one is running.
- A cancel control stops the scan; because the scan only reads, the target is
  left byte-for-byte unchanged.
- Sanitized provider failures appear in the provider panel rather than only in
  a dialog, and deterministic results stay available when Claude fails.
- Open Report Folder becomes available once an export succeeds.
- Keyboard focus reaches every primary control and accessible names are set for
  screen readers.

## Tests

Dashboard UI tests run against a real Qt widget tree on the offscreen
platform, covering clipping at five DPI scales, sidebar scrolling, provider
panel visibility and states, compact metric rendering, table resize behaviour,
running/complete/failed/cancelled states, long Windows paths, long profile
names, empty and large result sets, keyboard focus order, and the
double-start guard. They skip cleanly when PySide6 is absent.

## Visual polish pass

A follow-up pass corrected six presentation defects, all with regression
tests:

- **Cancel scan** stays disabled while idle and after every terminal state,
  and now *looks* disabled: `QPushButton#dangerButton` is an ID selector and
  was outranking `QPushButton:disabled`, so the button kept painting live red.
- **Pivot suggestions** show a compact empty state (evidence marker, heading,
  explanation) instead of an unexplained black void. No sample findings are
  invented, and the wording differs before and after a scan.
- **Empty tables** no longer raise a horizontal scrollbar: the grid and its
  empty state are no longer both visible at construction, the column floor
  adapts to the column count, and long values elide with the full text on the
  tooltip. The column fitter is shared by both table widgets.
- **Metric placeholders** render a muted, full-size em dash for "not
  measured". A measured zero is still shown as `0`; the two states are
  distinguishable in the accessible name as well as the colour.
- **Label bands** are gone. The base `QWidget` rule painted every label true
  black on lifted panels; one central `QLabel { background: transparent }`
  rule fixed all of them.
- **The status line** is sized from font metrics plus descent (not a fixed
  height) and elides long messages with a tooltip.

An adversarial review of the pass found three further defects, since fixed:
`text_dim` was lifted to `#7A8798` because 7pt captions measured 4.019:1 on
the raised card surface once their black backing was removed (below the 4.5:1
AA floor); the column fitter no longer ratchets its floor permanently
downward; and the Active scan panel starts its counters as unmeasured rather
than showing a fabricated `0 files / 0 roots` next to "No scan running".
