# Relic Auditor v0.5.0

v0.5.0 makes the existing deterministic engines explorable through a native,
local desktop interface. The scanner, Technical Truth analyzer, and Product
Resurrection pipeline remain the source of record; the dashboard does not
duplicate or weaken their safety boundaries.

## Native interactive dashboard

Install and launch:

```bash
python -m pip install -e ".[gui]"
relic dashboard
```

PySide6 is an optional dependency, so CLI-only installs remain dependency-free.
The dashboard can open with a folder picker or accept a target directly:

```bash
relic dashboard /path/to/estate
```

The app includes:

- A responsive background scan and visible phase progress
- Overview scorecards for inventory, projects, verified workflows, candidates,
  and duplicate groups
- A zoomable, pannable architecture canvas
- Search, sorting, selection, and evidence detail inspection across every table
- Dedicated capability, workflow, contradiction, and project-family views
- Offline product-opportunity exploration
- A large-estate file inventory backed by a table model

## Advisory cleanup planning

Candidate rows can be marked Keep, Extract, Archive, or Review. Decisions remain
in memory until report export and then appear in `cleanup-plan.json`. They do
not cause filesystem actions.

`cleanup-plan.json` is deterministic and explicitly records that Relic did not:

- Modify files
- Move files
- Delete files
- Execute source

There is no Delete decision and no file-operation control in the dashboard.
Items recommended as `delete-review` by the deterministic appraisal engine still
require a human Review or another non-destructive planning decision.

## Export boundary

Dashboard scans write no reports or persistent parser cache. Export uses the
existing canonical report writers and adds the cleanup plan. An export location
equal to or beneath the scanned estate is rejected before creating any output.

## Analysis modes

- Quick Inventory: bounded estate scan only
- Technical Truth: static workflow, capability, reachability, and contradiction
  analysis; enabled by default
- Product Resurrection: Technical Truth plus offline opportunity ranking

External market validation and external reasoning providers are intentionally
not exposed in the GUI.

## Compatibility

- Python 3.11+
- PySide6 6.7 through the current 6.x line
- Windows, macOS, and Linux desktop environments supported by PySide6
- Existing `relic audit` syntax and report schemas remain compatible

## Verification

The release test matrix covers the existing deterministic engines plus:

- Optional dashboard CLI parsing
- Useful missing-GUI dependency errors
- In-memory scans that do not write
- Automatic Technical Truth gating for Product Resurrection
- Read-only export behavior
- Rejection of reports inside the target
- Deterministic cleanup plans
- Rejection of destructive or unsupported decision values
