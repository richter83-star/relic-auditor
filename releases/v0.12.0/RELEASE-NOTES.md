# Relic Auditor 0.12.0 release candidate

This local RC is the production-foundation milestone. It adds an exact,
fail-closed Codex execution profile; active builder cancellation with process
tree termination and checkpoint restoration; Ed25519-signed update manifests;
signed entitlement refresh; persistent provider runtime truth; and clearer,
more readable five-step desktop guidance.

Generic native execution and the Claude assisted-build preview are blocked in
the production policy. Normal installs also remain Free and cannot trust the
stable update channel until external public keys are provisioned. In-app
installation additionally requires a trusted Dracanus AI Authenticode
certificate and permanent public hosting.

No tag or GitHub Release was created. No installer is included in this local
artifact set; the complete Windows workflow is still a required external gate.
